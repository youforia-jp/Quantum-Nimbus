# Quantum Nimbus - Master Project Document

## 1. Project Overview
**Quantum Nimbus** (also referred to as Project Nimbus) is a visionary hardware and software startup aiming to revolutionize the cannabis consumption experience. The company’s core mission is to champion user safety, control, consistency, and well-being through advanced technology.

**The Problem:** The current vape and cannabis market is plagued by a lack of consistency and safety, including the risk of heavy metals from poor hardware (like lead-based solder or low-quality heating coils) and contaminants in the oil (Vitamin E Acetate, pesticides).

**The Solution:** The **Nimbus Elevate** line of smart vaporizers, equipped with the **NIMBUS IQ System**. These devices are designed to remove the guesswork, automatically applying the optimal heating profile for any given substance, ensuring safety, and providing the user with detailed usage feedback.

## 2. Core Technologies & Product Lines

### NIMBUS IQ System
An intelligent system designed to automatically identify the contents of a universal 510-thread cartridge (e.g., Delta-8, Delta-9, CBD) and adjust the heating profile for optimal vaporization.
- **Auto Identification & Heating:** Uses sensors (or NFC tags on cartridges) to detect the exact compound and apply optimal temperature curves to prevent burning and harmful byproducts.
- **Overuse Alerts & Session Tracking:** Actively monitors user consumption (puff count/duration) and provides alerts via the device screen or haptic feedback if predefined usage thresholds are crossed.
- **Companion App (v3 Concept):** A smartphone app connected via Bluetooth Low Energy (BLE) that handles heavy processing. Features include:
  - Custom heating profiles (e.g., "Flavor Focus").
  - Reactive LED controls on the device.
  - Detailed usage tracking and battery health monitoring.
  - NFC seamless pairing.

### Hardware Lines
- **The Frontier:** A reusable 510-thread system focusing on premium materials (bead-blasted aluminum, walnut accents) and a tactile lever mechanism.
- **Astro Nimbus Line:** Devices with a celestial aesthetic, ergonomic design, and dynamic lighting. The "Pro" version features a "rocket door opening" mechanism.
- **My NIMBY Line:** An interactive, emotionally engaging companion targeting the "kidult" market, featuring a cutesy storm cloud aesthetic and "Gamified Wellness Loop."
- **The Frontier Rx:** A TCUP-compliant medical device for the Texas market, built with biocompatible materials and a secure authentication system for medical usage.

### The "Texas Nimbus" Pivot
A strategically simplified, rugged device intended for initial market entry in Texas. It features a "Cowboy Core" aesthetic, omits the complex AI-driven ID system for now, and relies on manual button-activated heating while keeping basic safety features (overuse alerts) and a Texas-shaped reactive LED.

### Nimbus Elevate Daily (Nootropic Supplement)
A complementary wellness supplement aimed at alleviating "brain fog" and mental fatigue associated with the next-day effects of cannabis use. It is marketed independently for "Clarity & Focus" (e.g., as "Nimbus Apex Focus") using compliant general wellness language to support cognitive resilience.
